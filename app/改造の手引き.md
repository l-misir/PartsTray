# 改造の手引き

PartsTray を自分好みに変えたい人向けの案内です。無料のチャット AI（ChatGPT・Claude・Gemini など）にファイルを貼って頼む前提で書いています。

## 1. まず、改造しなくてもできること

多くのことは**設定画面**で変えられます。プログラムを書き換える必要はありません。

**設定画面の開き方**（どれでも開けます）
- 通知領域のオウム・CPU 使用率・温度・メモリ・電池のアイコンを左クリックする（その設定欄へ移動）
- アイコンを右クリックして「設定…」を選ぶ
- `PartsTray.exe` をもう一度起動する

**設定画面で変えられること**
- 出すアイコンを選ぶ（オウム・CPU・温度・メモリ・電池）
- 数字と背景の色（CPU 使用率・温度・メモリ）、オウムの動き
- 電池のアイコンに出さない機器と、機器の種類（マウス・キーボード・ヘッドホン・イヤホン・ゲームパッド・スマホ・タブレット・その他）
- タスクバーの明るさ（自動・明るい・暗い）
- マウスジェスチャーの割り当て
- 肩代わりする 6 ボタンの割り当て（好きなキー、押しながらホイールで切り替え用の Hold）
- 本当の最大化・最大化しているアプリの切り替えのキー
- Windows の起動時に自動で起動するかどうか

設定は `PartsTray.exe` と同じフォルダーの `config.json` に保存されます。アプリが動いている間にこのファイルを手で書き換えても、1 秒ほどで反映されます。設定の一覧と意味は [README.md](README.md) にあります。

## 2. 改造するのに必要なもの

1. Windows 10 / 11
2. **.NET 9 SDK**。Microsoft の公式サイトから入れてください。
3. このフォルダー一式（`app` フォルダー）

### ビルドと確認のしかた

`app` フォルダーの 1 つ上のフォルダーで、次のコマンドを実行します。

ビルドだけをするとき：

```bash
dotnet build app/PartsTray.sln
```

テストをするとき（全部「合格」なら、今までの動きを壊していません）：

```bash
dotnet test app/PartsTray.sln
```

自分で使う exe を作るとき（`app/publish` に出来ます）：

```bash
dotnet publish app/PartsTray/PartsTray.csproj -c Release --self-contained false -o app/publish
```

- 作り直す前に、通知領域のメニューで PartsTray を終了してください。動いたままだと上書きできません。
- `--self-contained false` で作った exe を動かすには、その PC に **.NET 9 デスクトップ ランタイム**が必要です。ランタイムを入れずに動かしたい場合は、`--self-contained true -r win-x64` で作ります。ファイルはかなり大きくなります。
- 新しく作った exe でも、`config.json` を同じフォルダーに置けば設定をそのまま使えます。

## 3. 変えたいこと別：開くファイル

ファイルは、AI に貼りやすいよう、ほとんどを 300 行以下に分けてあります。どのファイルも、1〜2 行目に「何をするファイルか」「何を変えるときに開くか」が書いてあります。

### 電池のアイコン

|---|---|

| 輪の太さ、充電中の稲妻、切断中の薄さ、100% の虹の輪 | `PartsTray/BatteryIcon.cs`（虹の色は `PartsTray.Core/Palette.cs` の `Rainbow`、回し方は `PartsTray/BatteryModule.cs`） |

### マウスジェスチャー

| 変えたいこと | 開くファイル |
|---|---|
| 判定のしかた（どれだけ動かしたら 1 画とみなすかなど） | 設定画面で変えられます。仕組みは `PartsTray.Core/GestureEngine.cs` |
| ジェスチャーで実行する動作を増やす | 下の「動作を増やすとき」を見てください |
| 右ボタンの解放を見失ったときの回復・左右入れ替え対応 | OS 確認は `PartsTray/GestureModule.Release.cs`、状態の終了は `PartsTray.Core/GestureEngine.RightWheel.cs`、検証は `PartsTray.Tests/MissedRightReleaseTests.cs` |

**動作を増やすとき**

今ある動作は「戻る・進む・更新・閉じる・最小化」の 5 つです。新しい動作（例：「最大化」）を足すには、次の 5 か所すべてに名前を足します。

1. `PartsTray.Core/GestureSettings.cs`：使ってよい動作の一覧（`Validate` の中）
2. `PartsTray.Core/SettingsText.cs`：設定画面から読むときの一覧
3. `PartsTray/SettingsWindow.Gesture.cs`：設定画面の選択肢
4. `PartsTray.Core/GestureEngine.cs`：画面に出す日本語の名前
5. `PartsTray/WindowsGestureServices.cs`：実際に Windows へ送る処理

AI に頼むときは、この 5 つのファイルをまとめて貼ってください。

### マウスの肩代わり（MX Master 4 専用）

`PartsTray.Core/GapSession.cs` と `GapSession.*.cs` です。ロジクールの MX Master 4（Logi Bolt 接続）専用の機能で、最初は切れています。接続状態と受信の入口は `GapSession.cs`、適用順序・ボタン動作は `Commands`、Options+ と押下の通知は `Notifications`、送信検査・再送は `Worker`、接続済み機器の識別・後片付けは `Discovery` に分けています。各ファイルは 300 行以内です。

ボタンを足すときは `ButtonOrder`、設定画面の名前・選択肢、検査、テストを合わせて変更します。未設定の CID は横取りしないこと、Options+ への引き継ぎ後は入力を送らないこと、後片付けで Options+ の横取りを解除しないことを保ってください。任意キーと Hold の利用方法は [README.md の指示書 U の節](README.md#肩代わりの-6-ボタンと任意のキー指示書-u) を参照してください。

## 4. AI への頼み方

### 頼み方の例

ファイルの中身を全部コピーして、次の文の後ろに貼ります。

```text
Windows の通知領域に出る C# (.NET 9, WinForms) のアプリを改造したいです。
次のファイルを変えてください。

やりたいこと：（例）イヤホンの絵の軸を 1 ドット太くしたい

お願い：
- やりたいことに関係する部分だけを変えてください
- 変えた後のファイル全体を出してください
- ほかのファイルも変える必要があるときは、先にファイル名と理由を教えてください

（ここにファイルの中身を貼る）
```

### うまくいかなかったとき

ビルドでエラーが出たら、エラーの文（`error CS…` で始まる行）と、そのファイルの中身を AI に貼って「このエラーを直してください」と頼みます。

テストで「失敗」が出たら、失敗したテストの名前と、メッセージを貼ります。わざと動きを変えた場合は、テストも合わせて直してもらいます。

### うまく頼むコツ

- 1 回に頼むことは 1 つにする
- 「どう見えるようにしたいか」を具体的に書く（例：「20 ドットのアイコンで、上から 8 行目」）
- 変える前のファイルは、別の場所にコピーして残しておく

## 5. やってはいけないこと

- **通知アイコンを作る順番を変えない。** Windows は、通知領域のアイコンを「アプリ＋番号」で覚えています。順番が変わると、表示・非表示の設定や並びがずれます。番号の表は `PartsTray/TrayIds.cs` にあります。アイコンを増やすときは、今ある番号の後ろに足してください。
- **`config.json` の項目名を変えない。** 名前を変えると、今までの設定が読めなくなります。新しい項目は足すだけにしてください。
- **`PartsTray/Assets/parrot` の中の `LICENSE-RunCat365.txt` と `README.txt` を消さない。** オウムの絵は RunCat365（Apache License 2.0）から借りているので、配るときにはライセンスの文が必要です。
