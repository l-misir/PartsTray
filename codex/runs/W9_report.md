`"Tahoma, Regular, Pixel, Square2"` を追加しました。20 ドット枠の「37」は従来の **13×9** から **13×13** に、16 ドット枠では **11×8** から **9×9** になります。Tahoma 標準・にじみなしのまま、10〜99 のすべてで字間 1 ドットを含む横幅と高さが一致します。`Square2` は明示した場合だけ有効です。

[比較見本「縦長の比べ.png」を開く](<../../codex/見本/数字100/縦長の比べ.png>)。①従来、②Square2、③Core Temp と同じ Tahoma 標準 8 pt を暗・明の両背景で並べ、各数字の下に実測寸法を載せました。

| アイコン枠 | 単独・1桁 | 単独・2桁 | 単独・3桁 | 2段表示の各段・2桁 |
|---|---:|---:|---:|---:|
| 16 ドット | 4×9 | **9×9** | 14×9 | 7×7 |
| 20 ドット | 6×13 | **13×13** | 20×13 | 9×9 |
| 24 ドット | 7×15 | **15×15** | 23×15 | 11×11 |
| 32 ドット | 10×21 | **21×21** | 32×21 | 15×15 |

いずれも実際に描いた幅×高さです。温度とメモリの2段表示にも、各段の高さで同じ決まりを適用しました。GDI が「1」などで目的の幅を飛ばす場合だけ、1 ドット狭い字形のうち、インクの最も少ない列を複製しています。

**検証は全件合格です。** 指定条件でのビルドは警告・エラーともに 0 件、`dotnet test` は **1,251 件**合格しました。`Square2` の実画素検証は **1,208 件**で、0〜150 の全値について枠内への収まり、字間、にじみの有無を確認しました。

`config.json` の設定例です。アイコン別のフォントを設定している場合は、その項目にも同じ値を指定します。

```json
{
  "monitor": {
    "digitStyle": "thin",
    "hundredStyle": "uniform",
    "digitFont": "Tahoma, Regular, Pixel, Square2"
  }
}
```
