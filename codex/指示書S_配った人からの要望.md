## 1. CPU 温度が動かない PC（Windows 10 で「16℃ から変わらない」）

PartsTray の既定の温度は ACPI の Thermal Zone（`PartsTray.Core/Monitor.cs` の `FromAcpi`）。PC によっては、ここに CPU と関係のない決まった値しか入っていない。16℃ は CPU としてありえない。

- ACPI の値が **20℃ 未満**なら CPU の温度ではないとみなす（`FromAcpi` で捨てる）
- ACPI の値が **5 分以上まったく変わらず**、その間に CPU 使用率が大きく動いた（例：最低と最高の差が 30 ポイント以上）なら、「この PC の ACPI の温度は CPU の温度ではない」と判断する。判定は `PartsTray.Core` の純粋なクラスにして、時計を渡してテストする
- 取れないと判断したら、温度のアイコンは数字の代わりに「--」（今の「読めない」ときの表示に合わせる）にし、説明文に「この PC は Windows から CPU 温度を読めません。設定の『温度の読み方』で Core Temp を選んでください」と出す。記録と通知は 1 回だけ
- いったん「動かない」と判断しても、値が動き出したら（変わったら）元に戻す
- Core Temp を選んでいるときは、この判定はしない

## 2. アイコンから設定を開いたら、そのアイコンの設定を出す

- 今は温度のアイコンの左クリック（と右クリックのメニューの「設定…」）で設定画面が開く。**どのアイコンから開いたか**を設定画面に渡し、関係するタブ（と、できればその欄）を最初に出す
  - オウム・CPU 使用率・温度・メモリ → それぞれの設定がある所（今の設定画面の作りに合わせる）
  - 電池のアイコン → 電池の設定。その機器の「機器の種類」の欄があれば、そこ
  - 隠したウィンドウのアイコンなど、ほかのもの → 今までどおり
- 右クリックのメニューの「設定…」も、右クリックしたアイコンに合わせる
- すでに設定画面が開いているときは、前に出してそのタブに切り替える

## 3. 設定画面を開くのが遅い

- まず、開くまでの時間を区切りごとに記録に出す（`Stopwatch`。例：「設定画面：作成 120ms・電池の一覧 900ms・表示まで 1100ms」）。どこが遅いかを Claude が実機で見る
- 重い読み込み（機器の一覧など、OS に問い合わせるもの）は、**画面を先に出してから**別のスレッドで読み、終わったら欄を埋める（読み込み中は「読み込み中…」と出す）。UI のスレッドで待たない
- タブの中身を、開いたときにまとめて作るのが重ければ、初めてそのタブを開いたときに作る形にしてよい（§2 で最初に出すタブは、すぐ作る）
- 動きと保存の決まり（適用・キャンセル・読み直し）は変えない

## 4. 数字の背景を自由な色に

- CPU 使用率・温度・メモリの数字のアイコンに、**背景の色**の設定を足す（それぞれ別に。既定は今と同じ透明）
- 設定は `#RRGGBB` か空（＝透明）。設定画面では、今の数字の色の欄と同じ作り（文字で入れる＋色を選ぶ画面）にし、「透明に戻す」ができるようにする
- 背景は、アイコンの枠いっぱいの塗り（角は少し丸めてよい。丸めの量は今のアイコンの雰囲気に合わせる）。数字の色との見やすさの自動調整（明るいタスクバーでの補正など）は、今の決まりを崩さない
- オウム・電池のアイコンには足さない
